# Employee Management System

A console-based Employee Management System developed using **Python and MySQL** for managing employees, attendance, leaves, projects, notifications, reports, and user activities.

## Features

* User authentication and login
* Role-based Admin and Employee portals
* Employee management
* Employee search and update
* Employee profile management
* Automatic employee code generation
* Attendance management
* Check-in and check-out
* Late attendance detection
* Working hours calculation
* Leave management
* Leave balance management
* Leave application and approval
* Leave rejection and cancellation
* Project management
* Employee project assignment
* Project status management
* Notifications
* Activity logging
* Employee reports
* Attendance reports
* Leave reports
* Project reports
* Admin dashboard
* Input validation
* Duplicate email and phone validation

## Technologies Used

* **Python**
* **MySQL**
* **mysql-connector-python**

## How to Run

### 1. Install Python

Install Python 3.x on your system.

### 2. Install MySQL

Install MySQL Server and create the required database and tables.

### 3. Configure Database Connection

Create/configure the local `config.py` file with your MySQL connection details.

**Do not upload `config.py` to GitHub because it contains database credentials.**

### 4. Install Required Package

Open the terminal in the project directory and run:

```bash
pip install -r requirements.txt
```

### 5. Run the Application

Run:

```bash
python main.py
```

## Login

Employee accounts are created automatically when an employee is added through the system.

The default employee username is based on the generated employee code.

Example:

```text
Username: EMP1001
```

The default password is generated by the application.

## Security Note

Database credentials and other sensitive configuration information should not be committed to the repository.

The `config.py` file is excluded using `.gitignore`.
